PashuMitra / Indian Bovine — Local Run Guide
=============================================

Requirements
------------
- Node.js 20 or newer (includes npm)
- Internet access the first time, to download JavaScript dependencies
- Optional: Python 3.10+ for the YOLO breed-detector service

Run the web application (Windows / PowerShell)
------------------------------------------------
1. Open PowerShell in this project folder:

   cd "C:\Users\SriHarishAnandhan\Downloads\Indian Bovine"

2. Install dependencies (first run only):

   npm install

3. Generate the Prisma database client:

   $env:DATABASE_URL = "file:C:/Users/SriHarishAnandhan/Downloads/Indian Bovine/db/custom.db"
   npx prisma generate

4. Start the development server:

   $env:DATABASE_URL = "file:C:/Users/SriHarishAnandhan/Downloads/Indian Bovine/db/custom.db"
   npx next dev -p 3000

5. Open the app in a browser:

   http://localhost:3000

Stop the server with Ctrl+C in the PowerShell window.

Database notes
--------------
- The project includes demo data in db/custom.db.
- The checked-in .env contains an original Linux database path. For Windows,
  use the DATABASE_URL command above before running Prisma or Next.js.
- Database APIs (animals, milk logs, health records, and forum) use this SQLite
  file. Do not delete it unless you intentionally want to reset local data.

Optional: YOLO breed-detector service
-------------------------------------
The web app starts without YOLO. When the service is unavailable, the classifier
falls back gracefully, but full hybrid detection requires the Python service.

1. Ensure the model exists here:

   python-services/yolo-detector/models/version4.pt

2. Create and activate a Python virtual environment:

   py -3 -m venv .venv
   .\.venv\Scripts\Activate.ps1

3. Install the detector dependencies:

   pip install -r python-services/yolo-detector/requirements.txt
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu

4. Start the service in a second PowerShell window:

   cd "C:\Users\SriHarishAnandhan\Downloads\Indian Bovine"
   $env:PORT = "8501"
   python -m uvicorn python-services.yolo-detector.main:app --host 127.0.0.1 --port 8501

5. Check its status:

   Invoke-WebRequest http://localhost:8501/health

Important: Python module paths cannot contain hyphens. If the command in step 4
does not work, use this alternative:

   cd python-services\yolo-detector
   python -m uvicorn main:app --host 127.0.0.1 --port 8501

AI features
-----------
The chat and VLM classifier routes use z-ai-web-dev-sdk. Their availability
depends on your local Z.AI configuration (for example .z-ai-config). The rest
of the application, including the demo data and dashboard, works without it.
